= 審查 NetApp CN1610 叢集交換器的移轉選項
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
請查看如何將雙節點無交換器式叢集移轉到使用 NetApp CN1610 叢集交換器的有交換器叢集。具體步驟取決於每個控制器上是兩個專用叢集網路連接埠還是單一叢集連接埠。

大多數系統需要每個控制器上有兩個專用的叢集網路連接埠。

FAS22xx 節點允許每個控制器上有單一叢集連接埠。

有兩種移轉方案可供選擇：

* link:migrate-switched-netapp-cn1610.html["從無交換器式叢集移轉至交換器式 NetApp CN1610 叢集"]
* link:migrate-fas22xx-systems.html["從無交換器式叢集（具有單一叢集網路連線的 FAS22xx 系統）移轉"]
