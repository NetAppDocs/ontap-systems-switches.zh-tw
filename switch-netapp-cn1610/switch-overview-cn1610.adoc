= NetApp CN1610 交換器的安裝與組態概述
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
CN1610 是一款高頻寬、可管理的第 2 層交換器，提供 16 個 10 Gigabit 小型可插拔增強型 （SFP+） 連接埠。

此交換器包含備援電源和支援熱插拔的風扇托架，可實現高可用度。這款 1U 交換器可安裝在標準的 19 吋 NetApp 42U 系統機櫃或第三方機櫃中。

此交換器支援透過主控台連接埠進行本機管理，也支援透過網路連線使用 Telnet 或 SSH 進行遠端管理。CN1610 包含一個專用的 1-Gigabit Ethernet RJ45 管理連接埠，用於頻外交換器管理。您可以透過命令列介面 （CLI） 輸入命令或使用基於 SNMP 的網路管理系統 （NMS） 來管理交換器。
