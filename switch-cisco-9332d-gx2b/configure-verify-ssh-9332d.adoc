= 驗證 Cisco Nexus 9332D-GX2B 交換器上的 SSH 日誌收集功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
確認 Cisco Nexus 9332D-GX2B 交換器上已啟用 SSH，以支援乙太網路交換器健全狀況監視器 （CSHM） 和日誌收集功能。

.開始之前
您必須使用串列埠控制台連接到交換器。

.步驟
. 確認 SSH 已啟用：
+
[listing, subs="+quotes"]
----
(switch) *show ssh server*
ssh version 2 is enabled
----
. 請確認 SSH 金鑰已啟用：
+
`show ssh key`

.下一步是什麼？
* 確認 SSH 已啟用日誌收集後，您link:../switch-cshm/cshm-overview.html["設定乙太網路交換器健康狀況監控"]。
+
** 設定乙太網路交換器健全狀況監控後，如果您想利用 Cisco 的 Smart Call Home 支援功能，您link:configure-smart-call-9332d.html["配置 Smart Call Home"]。


* 如果您將交換器設定為新 AFX 1K 或 AFX 2K 系統安裝的一部分，則必須 link:install-complete-afx-setup-9332d.html["完成 AFX 系統設定"]。
