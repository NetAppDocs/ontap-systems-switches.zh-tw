= Cisco Nexus 3132Q-V 交換器的組態需求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
對於 Cisco Nexus 3132Q-V 交換器的安裝和維護，請務必審查網路和組態需求。



[[configuration-requirements]]
== 配置要求

若要設定叢集，您需要為交換器準備相應數量和類型的纜線及纜線連接器。根據您初始設定的交換器類型，您需要使用隨附的主控台纜線連接到交換器的主控台連接埠；此外，您還需要提供特定的網路資訊。



[[network-requirements]]
== 網路需求

所有交換器組態都需要以下網路資訊：

* 用於管理網路流量的 IP 子網路。
* 每個儲存系統控制器和所有適用交換器的主機名稱和 IP 位址。
* 大多數儲存系統控制器都透過 e0M 介面進行管理，方法是連接到乙太網路服務連接埠（扳手圖示）。在 AFF A800 和 AFF A700 系統中，e0M 介面使用專用乙太網路連接埠。
