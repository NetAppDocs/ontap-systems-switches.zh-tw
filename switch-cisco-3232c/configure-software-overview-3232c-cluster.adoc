= Cisco Nexus 3232C 叢集交換器的軟體安裝工作流程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
請依照下列工作流程在 Cisco Nexus 3232C 叢集交換器上安裝 NX-OS 軟體和參考組態檔案 （RCF）。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"]link:setup-switch.html["配置交換機"]
[role="quick-margin-para"]
設定 3232C 叢集交換器。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"]link:prepare-install-cisco-nexus-3232c.html["準備安裝 NX-OS 軟體和 RCF"]
[role="quick-margin-para"]
Cisco NX-OS 軟體和參考組態檔 (RCF) 必須安裝在 Cisco 3232C 叢集交換器上。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]link:install-nx-os-software-3232c.html["安裝或升級 NX-OS 軟體"]
[role="quick-margin-para"]
在 Cisco 3232C 叢集交換器上下載並安裝或升級 NX-OS 軟體。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四"]link:install-rcf-3232c.html["安裝 RCF"]
[role="quick-margin-para"]
首次設定 Cisco 3232C 交換器後，安裝 RCF。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"]link:configure-ssh-keys.html["驗證 SSH 配置"]
[role="quick-margin-para"]
驗證交換器上是否啟用了 SSH 以使用乙太網路交換器健康監視器 (CSHM) 和日誌收集功能。
