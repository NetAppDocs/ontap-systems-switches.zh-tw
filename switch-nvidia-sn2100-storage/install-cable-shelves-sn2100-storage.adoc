= 為 NVIDIA SN2100 儲存設備交換器的 NS224 磁碟機櫃接線
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當直連式儲存設備不適合您的組態時，可以使用 NVIDIA SN2100 儲存交換器將 NS224 磁碟機櫃連接成交換器連接的儲存設備。

* NS224 電纜驅動貨架透過儲存交換器：
+
https://library.netapp.com/ecm/ecm_download_file/ECMLP2876580["NS224 驅動器機架的佈線交換器連接訊息"^]

* 安裝儲存交換器：
+
https://docs.netapp.com/us-en/ontap-systems-switches/index.html["AFF和FAS交換器文檔"^]

* 確認您的平台型號支援的硬體，例如儲存交換器和纜線。詳情請參閱 link:https://hwu.netapp.com/["Hardware Universe"^]。
