在安裝或升級 NVIDIA SN2100 儲存設備交換器之前，請先查看其組態需求。



[[installation-requirements]]
== 安裝要求

如果要建置包含兩個以上節點的ONTAP集群，則需要兩個受支援的集群網路交換器。您也可以使用額外的管理交換機，這些交換機是可選的。

您可以使用交換器隨附的標準支架，將NVIDIA SN2100 交換器 (X190006/X190106) 安裝到NVIDIA雙/單交換器機櫃。

有關佈線準則，請參閱 link:cabling-considerations-sn2100-storage.html["佈線和配置注意事項"]。



[[ontap-and-linux-support]]
== ONTAP和 Linux 支援

NVIDIA SN2100 交換器是一款運行 Cumulus Linux 的 10/25/40/100 Gb 乙太網路交換器。此交換器支援以下功能：

* ONTAP 9.10.1P3。 SN2100 交換器透過不同的交換器對為ONTAP 9.10.1P3 中的叢集和儲存應用提供服務。從ONTAP 9.10.1P3 開始，您可以使用NVIDIA SN2100 交換器將儲存和叢集功能組合到共用交換器配置中。
* Cumulus Linux (CL) 作業系統版本 4.4.3 。如需目前的相容性資訊、請參閱 link:https://mysupport.netapp.com/site/info/nvidia-cluster-switch["NVIDIA乙太網路交換機"^] 。
* 當交換器執行 Cumulus Linux 或 ONIE 時，您可以安裝 Cumulus Linux。
