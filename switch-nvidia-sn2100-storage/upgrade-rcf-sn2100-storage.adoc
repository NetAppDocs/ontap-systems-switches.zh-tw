= 升級 NVIDIA SN2100 儲存設備交換器上的 RCF 指令碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
升級 NVIDIA SN2100 儲存設備交換器上的參考組態檔案（RCF）指令碼，以設定連接埠指派和網路設定。

.開始之前
請確保您擁有以下物品：

* 交換器配置的目前備份。
* 一個功能齊全的群集（日誌中沒有錯誤或類似問題）。
* 當前的RCF。
* 如果您要更新 RCF 版本，則需要在 RCF 中進行啟動配置，以反映所需的啟動映像。
+
如果需要更改啟動配置以反映目前的啟動映像，則必須在重新套用 RCF 之前進行更改，以便在以後的重新啟動中實例化正確的版本。




CAUTION: 在安裝新的交換器軟體版本和 RCF 之前，必須清除交換器設定並執行基本設定。在清除交換器設定之前，您必須使用序列控制台連接到交換機，或保留基本設定資訊。

.RCF 指令碼版本
請根據您目前的 ONTAP 和 Cumulus Linux 版本選擇合適的儲存設備 RCF 指令碼版本。從  https://mysupport.netapp.com/site/info/nvidia-cluster-switch["NVIDIA SN2100 軟體下載"^] 頁面下載 RCF。

.關於範例
以下範例步驟顯示如何下載和套用儲存設備交換器的 RCF 指令碼。

範例指令輸出使用交換器管理 IP 位址 10.233.204.71，子網路遮罩 255.255.254.0 和預設閘道 10.233.204.1。

[[step-2-upgrade-the-rcf-on-the-switch]]
== 步驟 2：升級交換器上的 RCF

. 將 RCF Python 腳本複製到交換器：
+
[listing, subs="+quotes"]
----
admin@sw1:mgmt:~$ *pwd*
/home/cumulus
cumulus@cumulus:mgmt:~$ *cd /tmp*
cumulus@cumulus:mgmt:/tmp$ *scp <user>@<host:/<path>/RCF-v1.14-MSN2100-ST1*
ssologin@10.233.204.71's password:
RCF-v1.14-MSN2100-ST1                 100% 8607   111.2KB/s         00:00
----
. 套用 RCF Python 指令碼 *RCF-v1.14-MSN2100-ST1*：
+
[listing, subs="+quotes"]
----
cumulus@cumulus:mgmt:/tmp$ *sudo python3 RCF-v1.14-MSN2100-ST1*
[sudo] password for cumulus:
...
Step 1: Creating the banner file
Step 2: Registering banner message
Step 3: Updating the MOTD file
Step 4: Ensuring passwordless use of cl-support command by admin
Step 5: Disabling apt-get
Step 6: Creating the interfaces
Step 7: Adding the interface config
Step 8: Disabling cdp
Step 9: Adding the lldp config
Step 10: Adding the RoCE base config
Step 11: Modifying RoCE Config
Step 12: Configure SNMP
Step 13: Reboot the switch
----
+
RCF腳本會完成上述步驟。

+

NOTE: 如果遇到任何無法解決的 RCF Python 腳本問題，請聯絡我們。 https://mysupport.netapp.com/["NetApp支援"^]尋求幫助。

. 將先前對交換器配置所做的任何自訂設定重新套用。請參閱link:cabling-considerations-sn2100-storage.html["審查佈線和配置注意事項"]有關任何後續變更的詳細資訊。
. 將控制器儲存設備埠和 NS224 機櫃連接埠連接到交換器。
