= 了解 ONTAP 系統交換器
:allow-uri-read: 


[role="lead"]
ONTAP 提供 AFX 系統、叢集、儲存設備和共享的交換器，可交付內部通訊，並能夠在叢集內無中斷地移動資料和網路介面。

「前端」交換器提供與主機儲存的連接，而「後端」叢集交換器則提供兩個或多個NetApp控制器之間的連接。


NOTE: 僅支援經NetApp驗證的後端交換器（從NetApp訂購）。


CAUTION: 如果您要升級交換器，NetApp 建議您先完成 ONTAP 軟體升級，然後再對交換器進行軟體升級。



[[afx-systems-switches]]
== AFX 系統交換機

AFX 系統交換器可協助您建置快速、節能且節省空間的網路交換器。其小巧的體積和高連接埠密度使其成為處理大型網路的理想選擇。連接埠支援不同的傳輸速率，並可分割為多個連線。NetApp 支援的 AFX 系統交換器包括：

* Cisco Nexus 9808
* CiscoNexus 9332D-GX2B
* CiscoNexus 9364D-GX2A




[[cluster-switches]]
== 集群交換機

叢集交換器可讓您建立具有兩個以上節點的ONTAP叢集。NetApp支援的叢集交換器包括：

* 博通 BES-53248
* CiscoNexus 9336C-FX2




[[storage-switches]]
== 儲存交換機

儲存交換器可讓您在儲存區域網路 (SAN) 中的伺服器和儲存陣列之間路由資料。  NetApp支援的儲存交換器包括：

* CiscoNexus 9336C-FX2




[[shared-switches]]
== 共享交換機

共用交換器可讓您將叢集和儲存功能合併到共用交換器設定中，支援使用共用叢集和儲存 RCF。  NetApp支援的共享交換器是：

* CiscoNexus 9336C-FX2
