= 了解如何在 Cisco Nexus 9808 交換器上安裝或升級 NX-OS。
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 Cisco Nexus 9808 交換器上安裝或升級 NX-OS，以支援 AFX 2K 系統。


NOTE: NX-OS 的安裝或升級與參考設定檔案 （RCF） 的安裝或升級相互獨立。如果您要同時安裝或升級 NX-OS 和 RCF，建議您先安裝或升級 NX-OS。

* link:configure-install-nxos-9808.html["安裝 NX-OS"]
+
在進行新的 AFX 2K 系統安裝、更換監督模組或將交換器重設為原廠預設值時，您需要在交換器上安裝 NX-OS。

* link:configure-upgrade-nxos-9808.html["升級 NX-OS"]
+
您可以透過升級交換器上的 NX-OS 來支援 AFX 2K 系統上的新硬體或新的 ONTAP 版本。
