:allow-uri-read: 
:icons: font
:imagesdir: ../media/

您可以對交換器執行以下維護任務：

* link:maintain-replace-frus-9808.html["更換 FRU"]
* link:maintain-reset-switch-9808.html["將交換器重設為出廠預設值"]
