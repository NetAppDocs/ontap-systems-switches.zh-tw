= 完成 AFX 系統設定 - Cisco Nexus 9808
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
完成 Cisco Nexus 9808 交換器設定程序後，您需要前往 AFX 系統文件網站，開啟 AFX 2K 系統中的儲存架和控制器電源，驗證交換器連線能力，並完成 AFX 系統設定。

.開始之前
* 您必須已完成 link:configure-switch-workflow-9808.html["配置交換器工作流程"] 中的交換器設定程序。
* 每個交換器都必須連接到主控台，或者您必須擁有對每個交換器的遠端存取。


.步驟
. 請依照 link:https://docs.netapp.com/us-en/ontap-afx/install-afx-2k/power-on-hardware.html["啟動您的 AFX 2K 儲存系統"^] 程序完成 AFX 2K 系統的開機和設定步驟。


.下一步是什麼？
開啟儲存架和控制器的電源並完成 AFX 2K 系統設定後，您就可以使用 AFX 系統了。
