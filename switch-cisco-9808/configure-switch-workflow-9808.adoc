= Cisco Nexus 9808 交換器的設定工作流程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
請依照此工作流程設定 Cisco Nexus 9808 交換器，以進行 AFX 2K 系統安裝、監督模組更換或將交換器重設為原廠預設值。

當您link:install-configure-switches-in-afx-workflow-9808.html["安裝並設定新的 AFX 2K 系統"]、link:maintain-replace-frus-9808.html["更換 FRU"]或link:maintain-reset-switch-9808.html["將交換器重設為出廠預設值"]時，可能會根據需要將您引導至此工作流程或此工作流程中的各個主題。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"]link:configure-complete-initial-setup-9808.html["完成初始交換器設置"]
[role="quick-margin-para"]
交換器通電後，將開始啟動並進入設定精靈。系統會提示您回答一系列問題，以完成交換器的初始（啟動）設定。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"]link:configure-review-cabling-config-requirements-9808.html["審查佈線和配置要求"]
[role="quick-margin-para"]
審查佈線和配置要求。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]link:configure-install-nxos-9808.html["安裝 NX-OS"]
[role="quick-margin-para"]
在支援 AFX 2K 系統的交換器上安裝最新版本的 NX-OS。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四"]link:configure-install-upgrade-rcf-overview-9808.html["安裝 RCF"]
[role="quick-margin-para"]
在支援您的 AFX 2K 系統的交換器上安裝最新版本的參考組態檔案（RCF）。該連結將帶您進入參考組態檔案（RCF）安裝或升級概述主題，其中包含您在安裝 RCF 之前需要了解的資訊。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"]link:configure-verify-ssh-9808.html["驗證 SSH 是否用於日誌收集"]
[role="quick-margin-para"]
請確認 SSH 已啟用，以便您可以使用乙太網路交換器健康監視器 (CSHM) 日誌收集功能。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["六"]link:../switch-cshm/cshm-overview.html["設定乙太網路交換器健康狀況監控"]
[role="quick-margin-para"]
設定乙太網路交換器健康監控 (CSHM)，以確保交換器的運作健康，並收集交換器日誌以進行偵錯和故障排除。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png["七"]link:configure-smart-call-9808.html["設定 Smart Call Home （選用）"]
[role="quick-margin-para"]
ONTAP 支援乙太網路交換器健康監控 (CSHM)，用於監控 AFX 叢集交換器，並能夠收集交換器診斷日誌。Cisco 的 Smart Call Home 是一項選用功能，可提供主動支援並協助您解決交換器可能出現的任何問題。

.下一步是什麼？
* 如果您將交換器設定為新 AFX 2K 系統安裝的一部分，則必須link:install-complete-afx-setup-9808.html["完成 AFX 系統設定"]。
* 如果您在更換管理模組時配置了交換器，或將交換器重設為出廠預設設定，則交換器應可正常運作。
