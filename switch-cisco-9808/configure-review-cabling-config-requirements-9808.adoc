= 檢查佈線和設定需求 - Cisco Nexus 9808
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您正在安裝 Cisco Nexus 9808 交換器作為新的 AFX 2K 系統安裝的一部分、更換監督模組，或將交換器重設為出廠預設設定，則必須檢閱以下佈線和組態需求。



[[hard-code-the-speed-on-breakout-ports]]
== 將分線連接埠的速度硬式編碼

您必須將交換器分線連接埠（4x100GbE）的速率硬編碼為 100GbE。如果您不硬編碼速率，這些連接埠將無法啟動，並處於錯誤停用狀態。

例如，若要在分支連接埠 19-35 上硬編碼 100GbE，請在設定模式下執行下列操作。範例中顯示的是套用於第一台交換器 （cs1） 的命令。您需要對第二台交換器重複這些命令。

[listing, subs="+quotes"]
----
(cs1)# *configure terminal*
Enter configuration commands, one per line. End with CNTL/Z.
(cs1)(config)# *interface e1/19/1-4,e1/20/1-4,e1/21/1-4,e1/22/1-4,e1/23/1-4,e1/24/1-4,e1/25/1-4,e1/26/1-4,e1/27/1-4,e1/28/1-4,e1/29/1-4,e1/30/1-4,e1/31/1-4,e1/32/1-4,e1/33/1-4,e1/34/1-4,e1/35/1-4*
(cs1)(config-if)# *speed 100000*
(cs1)(config-if)# *no negotiate auto*
(cs1)(config-if)# *exit*
(cs1)(config)# *exit*
(cs1)# *copy running-config startup-config*
----
.下一步是什麼？
滿足佈線和配置要求後，您link:configure-install-nxos-9808.html["安裝 NX-OS"]。
