= 檢閱 Cisco Nexus 92300YC 叢集交換器的 Smart Call Home 需求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
查看在 Cisco Nexus 92300YC 叢集交換器上設定 Smart Call Home 以啟用關鍵系統事件自動電子郵件通知的要求。

Cisco 的 Smart Call Home 可監控您網路中的硬體和軟體元件。當發生關鍵系統設定問題時，它會產生電子郵件通知，並向目標設定檔中設定的所有收件者發出警報。

[NOTE]
====
ONTAP 支援乙太網路交換器健康監控 （CSHM），用於監控 AFX 叢集交換器，並能夠收集交換器診斷日誌。

Cisco 的 Smart Call Home 是一項可提供主動支援並協助您解決交換器可能出現的任何問題的選項。

====
在使用 Smart Call Home 之前，請注意以下要求：

* 必須架設郵件伺服器。
* 交換器必須與郵件伺服器建立IP連線。
* 必須設定聯絡人姓名（SNMP 伺服器聯絡人）、電話號碼和街道地址資訊。這是為了確定所接收訊息的來源。
* CCO ID 必須與貴公司適用的Cisco SMARTnet 服務合約關聯。
* 設備必須已安裝Cisco SMARTnet 服務才能註冊。


這 http://www.cisco.com/c/en/us/products/switches/index.html["Cisco支援網站"^]包含有關配置智慧呼叫中心命令的資訊。

Smart Call Home 可在新系統安裝和設定期間進行設定，也可在之後進行設定。
