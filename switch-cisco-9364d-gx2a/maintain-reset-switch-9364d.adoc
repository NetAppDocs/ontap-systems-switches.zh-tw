= 將交換器重設為出廠預設值 - Cisco Nexus 9364D-GX2A
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
當 Cisco Nexus 9364D-GX2A 交換器停用或發生故障且無法恢復，需要手動重新設定時，您可以將該交換器重設為原廠預設值。

.開始之前
您必須使用串列埠控制台連接到交換器。

.關於此任務
* 此任務會重置管理網路的配置。
* 此程序中使用的  `reload` 命令會重新啟動交換器，從而中斷所有通過該交換器的網路流量。（您應在交換器未使用時的維護期間執行此程序。）


.步驟
. 清除現有啟動配置：
+
`write erase`

+
[listing, subs="+quotes"]
----
(cs2)# *write erase*

Warning: This command will erase the startup-configuration.
Do you wish to proceed anyway? (y/n) [n] *y*
----
. 重新載入 NX-OS：
+
`reload`

+
[listing, subs="+quotes"]
----
(cs2)# *reload*

This command will reboot the system. (y/n)? [n] *y*
----
+
系統重新啟動並進入設定精靈。

+

NOTE: 重啟過程中，如果收到「Abort Auto Provisioning and continue with normal setup? （yes/no）[n]」提示，請回答 *yes* 以繼續。

. 如果交換器要停用，則此程序完成；否則，需要使用 link:configure-switch-workflow-9364d.html["配置交換器工作流程"] 設定交換器。
