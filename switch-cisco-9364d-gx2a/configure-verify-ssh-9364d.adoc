= 驗證 SSH 日誌收集功能 - Cisco Nexus 9364D-GX2A
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您正在設定交換器，作為新的 AFX 1K 或 AFX 2K 系統安裝、交換器更換或恢復原廠預設設定的一部分，若要使用乙太網路交換器健康監視器 (CSHM) 日誌收集功能，您必須確認交換器上是否已啟用 SSH。

.開始之前
您必須使用串列埠控制台連接到交換器。

.步驟
. 確認 SSH 已啟用：
+
[listing, subs="+quotes"]
----
(switch) *show ssh server*
ssh version 2 is enabled
----
. 請確認 SSH 金鑰已啟用：
+
`show ssh key`

+

.下一步是什麼？
* 確認 SSH 已啟用日誌收集後，您link:../switch-cshm/cshm-overview.html["設定乙太網路交換器健康狀況監控"]。
+
** 設定乙太網路交換器健全狀況監控後，如果您想利用 Cisco 的 Smart Call Home 支援功能，您link:configure-smart-call-9364d.html["配置 Smart Call Home"]。


* 如果您將交換器設定為新 AFX 1K 或 AFX 2K 系統安裝的一部分，則必須 link:install-complete-afx-setup-9364d.html["完成 AFX 系統設定"]。
